AI Agents Bootcamp

Ten progressive examples of AI agents built with PydanticAI and FastAPI.

Connecting...
01 Basic Agent cli only

Minimal agent with synchronous execution. No API endpoint.

prompt → agent → text

Run directly: python 01_basic_agent.py

02 Structured Output POST /review

Returns Pydantic-validated structured data: rating, pros, cons, one-liner.

movie name → film critic agent → MovieReview{}
03 Tools Agent POST /ask

Agent picks from three tools: dice roller, clock, and calculator.

question → agent ↔ tools → answer
04 Dependencies Agent POST /assist

Runtime dependency injection. Agent adapts persona from your inputs.

name + style → dynamic prompt → agent → styled answer
05 Streaming GET /story

Token-by-token streaming. Watch the text appear as the model generates it.

topic → storyteller agent → stream
06 Debate Arena POST /debate

Three agents: a passionate advocate, a cold logician, and a judge.

topic → debater for ↔ debater against → judge → verdict
07 Agent Pipeline POST /blog

Three agents chained: researcher, writer, editor. Each transforms the previous output.

topic → researcher → writer → editor → blog post
08 Roast My Code POST /roast

Gordon Ramsay of code review. Finds real bugs while being dramatic about it.

code → roast agent → RoastResult{}
09 Whisper + Analysis POST /transcribe

Whisper transcribes audio, then an agent extracts summary, action items, and sentiment.

audio → whisper → analyzer agent → analysis
10 Memory Chat POST /chat

Stateful conversation. The agent remembers what you said earlier in the session.

message → chat agent ↔ session memory → response
